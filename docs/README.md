# OctoAcme Project Management Docs

## Overview
OctoAcme uses a lightweight, structured project lifecycle: initiation, planning, execution, release, and retrospective. Teams define customer outcomes early, break work into testable increments, track risks and dependencies continuously, and release with clear verification and rollback practices. Roles and communication cadences are explicit so ownership stays clear, decisions are evidence-based, and improvements are captured after each sprint, release, or incident.

## Core Principles
- **customer-first**: prioritize customer value and usability.
- **iterative delivery**: deliver in small, testable increments.
- **clear ownership**: assign accountable PM, Product, and delivery owners.
- **data-informed decisions**: use metrics and outcomes to guide priorities.
- **psychological safety**: encourage candid feedback, learning, and blameless retrospectives.
